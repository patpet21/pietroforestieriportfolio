# Real media integration

Preferred files: `public/project-media/*.webp` (see `src/data/brandMedia.ts`).

The user supplied authentic PrivacyGate screens, project badges, the PropertyDEX icon and two n8n screenshots in chat. The GitHub connector cannot directly read binary chat attachments. **These binary images are not yet uploaded to GitHub.** This implementation activates the mapping with durable fallback files from the user's other public repositories, or existing concept SVG files. Copy the optimized project-media assets into `public/project-media` in this repository to activate all original uploaded visuals.

After publishing the assets, the image gallery can show Protect, Restore, MCP, Gmail, Edge, Microsoft Store, AI PM Lab and n8n workflow screens. Do not label mockups as real screenshots. No GitHub Actions are required.
